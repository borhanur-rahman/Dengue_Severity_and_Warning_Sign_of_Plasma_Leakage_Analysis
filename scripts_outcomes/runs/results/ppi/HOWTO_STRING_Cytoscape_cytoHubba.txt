PPI + hub-gene workflow (per axis)
==================================

REPRODUCIBILITY RECORD: STRING min score = 0.700, cytoHubba method = MCC. Report these in the manuscript.

1. STRING (https://string-db.org)
   - Search > 'Multiple proteins'
   - Paste the contents of <axis>_ppi_genes.txt
   - Organism: Homo sapiens
   - Minimum required interaction score: 0.700 (high confidence)
   - Export > send network to Cytoscape (stringApp), or download 'network coordinates'

2. Cytoscape
   - Load the STRING network (stringApp) for the axis
   - File > Import > Table from file: <axis>_node_attributes.tsv (key column = gene)

3. cytoHubba (Apps > cytoHubba)
   - Target network: the axis network
   - Compute node scores by: MCC (recommended), also Degree and MNC
   - Export the top 10 (or top 15) ranked nodes = HUB GENES for that axis

Report hubs per axis. Because the input genes come from enriched pathways,
hubs will tend to be the central genes of each axis's dominant program
(e.g. interferon hub for severity, chemokine/cytotoxic hub for leakage) -
frame them as 'central genes of the axis programme', which is standard.
